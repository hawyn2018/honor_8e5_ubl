# 2.8.13：摘要比较成功返回与原生日志

本次以已发布 hnubl 2.8.12 为基线，更新至 2.8.13 / code 86，独立 fakebl 同步为 1.3.11 / code 34。Freedom 保持既有发行版本。

HashDescriptor 摘要比较在已定位的比较调用位置采用本地成功返回值，后面的原生结果消费与继续分支保持。相关校验失败的原生日志与上报恢复，不通过额外抑制补丁拦截输出。成功结果自然不进入摘要不匹配分支；这与删除日志器、删除日志字符串或全局禁止失败上报不同。本地接受策略不表示输入分区经过真实摘要比较或签名认证通过。

适配按真实比较输入、长度参数、调用和返回值消费关系定位，兼容寄存器 / 地址变化、部分指令调整和已有成品重新导入，不使用型号、版本或固定地址表。格式、长度、指针和实际读取失败等分支按各自已实现逻辑处理，不把本项表述为全部引导错误都返回成功。

保留 2.8.12 的 special SDAM 可选兼容及原有 PSS 策略；提权实现与资产、签名配置、内置父 ABL、OTA 模块、KBL runtime 和其他既有资产保持上版内容。本轮不重编译 KBL runtime，也不修改设备实际保存的认证或防回滚状态。

实际验证需分别记录核心回归、原镜像与旧成品重新导入、候选字节和原生日志 / 上报路径，以及 screenoff 后的 KBL RAM 测试。本文不预填测试结果，最终交付报告以本轮真实证据为准；当前测试设备的成功不代替其他设备的运行时验证。
