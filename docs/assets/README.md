# hnubl branding

The PNG and SVG preserve the current app icon's 108 × 108 vector geometry and proportions.
They use the packaged default primary color `#B6007C` and white `#FFFFFF`, matching
the app's Pink / Vibrant / Material 2021 button palette.

Sources: `app/src/main/res/drawable/ic_launcher.xml`,
`app/src/main/res/values/launcher_colors.xml`, and the `AppLauncherIcon` renderer.
The SVG is the editable vector; the PNG is a 1024 × 1024 README rendering.
Project-owned artwork follows the repository's AGPL-3.0-only license.
