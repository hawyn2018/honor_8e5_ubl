# 2.8.3 可见间距

首次弹窗的精简提示采用 Trim.Both，联系方式仅首行 Trim.FirstLineTop、末行 Trim.LastLineBottom，其余边界继续保留完整 21sp 行高。消除行高外缘留白造成的“提示到链接”与“链接到按钮”空白不一致，内部相邻链接和长链接自然换行的行距保持。

段落和链接组之间使用 12dp 基础间距。仅首次弹窗的链接组下方加入随系统字体缩放的 5sp 视觉补偿，使末行文字到按钮轮廓的留白与上方两段文字之间的留白一致。普通页面及许可证详情的非紧凑页脚保持原样；提示完整说明、第一段全文、GitHub 完整跳转和复制、固定同意按钮及持久化保持。

应用和内置模块同步为 2.8.3 / versionCode 76；模块只更新版本元数据。
