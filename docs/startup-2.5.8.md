# hnubl 2.5.8

启动时先显示简短检查页面，再以外部 su 的只读 `id -u` 返回结果决定初始页。只有退出码 0 且标准输出为 0 才进入 OTA；缺少 su、拒绝、UID 2000、异常或超时均进入提权页。检查使用所有候选路径共享的 3 秒预算，进程清理可能略多占用时间；管理器可显示正常授权弹窗。此检查不调用内置提权、不注册内置后端。

结果仅保存在 StartupModel 内存中：旋转不重复检查，已有分页位置不被 onResume 抢走。系统回收进程后会重新检查；新的 Compose 会话键防止恢复的旧分页绕过最新目的页。显式 open_root 请求优先进入提权页并取消待完成检查。
