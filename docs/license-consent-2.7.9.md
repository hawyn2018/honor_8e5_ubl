# 2.7.9 许可证弹窗与预加载

许可证弹窗显示时，应用在后方初始化并加载正常页面，点击同意后直接撤除遮罩，不再从同意时才开始加载。首次启动的正常只读状态检查可提前进行，业务操作仍由弹窗和既有同意状态守卫隔离。

弹窗外应用内容在支持 RenderEffect 的 Android 版本上使用毛玻璃模糊，并带轻微主题色遮罩；弹窗自身文字与按钮保持清晰。旧系统使用主题色遮罩作为显示降级，不因缺少模糊 API 影响同意操作。

从首次同意弹窗进入完整许可证阅读后，中英文全文的最后一项都提供“我同意”。按钮复用同一个同意保存回调，保存期间禁用重复点击，保存失败在阅读页底部显示原因并允许重试。文档未成功加载时不显示该底部按钮。普通设置页仍作为只读许可证查看入口。

同意记录继续沿用 `AGPL-3.0` 许可 ID，原已同意用户不重复确认。未同意时仍不能通过外部点击或系统返回取消门禁；可以选择退出应用。

许可证页顶部和首次弹窗采用同一份“软件及组件许可说明”，明确项目范围包括 hnubl 应用、随附修补器、OTA 模块、KBL 微内核及相关项目源代码。第三方代码、工具和预置镜像仍保留各自版权与许可；按“现状”提供以及担保、责任限制的说明指向 AGPLv3 第 15—17 条和适用法律，不改动许可证正文或加入额外再分发限制。

AGPL 中英文正文、同意状态存储、备份、解锁、OTA 事务及修补逻辑与 2.7.8 相同。本次应用与模块同步版本为 **2.7.9 / versionCode 70**；模块仅同步版本标识。
