# hnubl 2.9.6：完成页面偶发卡顿优化

本版基于 2.9.5。生产修改仅限可选的重启按钮标签观察器，应用和内置模块版本统一为 2.9.6，内部 versionCode 为 95。

## 稳定时停止重复界面工作

旧版每 2.5 秒状态轮询和布局事件均可触发整棵视图树扫描。新版将控件发现与状态读取分离：标签已识别且保持正确时，周期任务仅后台读取已有 STATE 协议；结果相同且没有待渲染变化时，不安排主线程任务，不扫描、读取或写入控件。尚未匹配目标时保留受滚动保护的低频查找，匹配成功后立即停止该兜底。

状态变化时，仅更新已跟踪的标签。文字已正确时不重复 setText。标签只负责显示，实际点击后的授权、暂停跳转、许可消费、续接、切槽和重启仍使用原门控及系统更新原流程。

## 滑动与真实内容变化

标准视图树滚动监听仅延后已有工作，纯滚动不会制造发现任务。持续滚动和惯性滚动期间不启动新发现；状态变化保存最新结果，静止后更新已跟踪按钮。真实布局内容变化在最后事件后 200ms 合并处理，旧的已排队任务不能越过新的滚动事件执行。

文字改变可能引发真实的异步布局事件。保留对该事件的合并发现，随后回到稳定状态；不采用“忽略下一次布局”或“写字后固定时段屏蔽布局”的规则，以免丢失同一帧新增的外部按钮、Dialog 或控件复用。

## 不触发布局事件的旧控件

固定尺寸 TextView 的原生换字可能只重绘而不触发布局事件。对已经匹配过的少量标签使用标准 TextWatcher 被动监听实际文字变化，原生改写时才安排异步验证；应用自身改字不递归，重复写入已经正确的文字也不制造刷新。控件复用为下载/安装文案后可继续以弱引用观察它恢复为重启文案。

首次尚未匹配目标的页面保留低频、受滚动保护的兜底发现；匹配成功立即停止重复查找。该路径补足无布局、焦点或生命周期事件的文字替换，不使用全局 setText 替换，不监听所有正文。

## 保留旧版识别能力

原有文字匹配函数与五组语义资源名称保持不变，包含简繁体重启文案、英文 restart now/reboot now 及实际资源中的本地化文本。完整发现先筛文字，仅对匹配者或已跟踪对象检查真实点击父链；已经改为“继续流程”的对象继续跟踪。

Resources 缓存按实际资源对象、包名和 Configuration 快照区分，语言和配置变化时失效。窗口能力仍按实际框架 API 选择，不加入固定机型、版本、混淆类名或控件 ID 表。

## 验证范围

主机回归覆盖稳定轮询、连续滑动、状态覆盖、过期任务、资源本地化与配置变化、正文控件成本、弱引用与清理；真机以同动作帧统计及发现/渲染/写字计数验证，展示状态一仅由测试提供者模拟，实际完成标记保持原值。测试不点击重启，不执行系统 OTA、切槽或分区写入。

应用功能源码、提权、备份、解锁、分区工具、ABL/EFISP 修补器、KBL、实际门控与 native slot 逻辑均保持来源版本。源码包不包含签名私钥或本地设备日志。
