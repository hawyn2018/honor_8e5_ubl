# 2.5.2 修补存储

本版本为 **2.5.2（versionCode 40）**，包名保持 `net.hawyn.honor8e5ubl`。

代码补丁按输入 PE 的实际节布局分配存储。新增代码自动使用调用点所在原有 RX 映射的零填充尾部；分配保留既有结构、节属性、对齐、容量、直接分支范围和计划区间互不重叠的核对，不增加机型、版本或固定地址适配表。

代码分配阶段取消引用风险推断。指令或数据中看似地址的数值、字符串、图片颜色值及其他对象引用，不再作为该项推断审计的阻断条件。其余 PE 结构、映射边界、输出字节和原有文字分配、复制容量核对继续执行。

重新导入旧成品时，已识别的补丁与已有存储位置继续复用；保持相同模式和定制文字的成品沿用现有重新导入流程。

本次更新不调整提权实现、备份范围、F2FS/GPT 流程、镜像来源、ABL 槽位选择、只读目标解除或刷写顺序。仍先提取源 ABL 并生成 efisp、保存备份，再执行既有分区和镜像写入流程，完成后的重启入口按所选模式提供。
