# 2.7.11 首次弹窗联系方式

首次许可证弹窗在“阅读完整许可证”按钮上方显示 QQ 群、酷安、Telegram 和 GitHub 四行联系方式，复用普通页面相同的链接与长按复制处理。

紧凑样式固定使用 12sp 字号、21sp 行高，与弹窗上方说明相同；每行垂直内边距为零，四行之间没有额外间距，长链接按实际宽度自然换行。

普通页面及中英文许可证全文底部仍使用默认样式（12sp 字号、20sp 行高、每行上下 12dp 内边距）。仅在许可证全文底部，GitHub 的显示文字省略 `https://`，显示为 `github.com/hawyn2018/honor_8e5_ubl`；点击与复制仍使用完整链接。首次弹窗和其他页面显示完整链接。首次同意保存、毛玻璃背景与应用预加载沿用 2.7.10。

中文译文与 English 原文在打开全文页面时一并加载，切换时复用同一个列表状态与段落位置，不再执行自动返回顶部，也不会短暂缩成加载提示再展开。设置页与首次弹窗内的完整许可证共用这一行为。

应用和内置模块同步为 2.7.11 / versionCode 72；模块仅更新版本元数据。
